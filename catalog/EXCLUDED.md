# Excluded sources

These sources were reviewed on 2026-11-25 and are **not** collected, because their terms do not allow redistribution or their license could not be confirmed. Do not add them without new, written evidence of an open license.

| Source | Why it is excluded |
| --- | --- |
| Christian Classics Ethereal Library (ccel.org) | Its [copyright policy](https://www.ccel.org/about/copyright.html) allows personal, educational and non-profit use only, and requires permission to republish. Get the same public-domain works from Project Gutenberg or Wikisource instead. |
| HistoricalChristianFaith/Commentaries-Database | Its LICENSE says some entries are excerpts of works still under copyright, included as fair use. Fair use does not carry over to a redistributed library. |
| NonlinearFruit/Creeds.json | Its README says the repo as a whole is not licensed for reuse, and lists several copyrighted texts and translations. |
| robertrouse/theographic-bible-metadata | Licensed CC BY-SA, but built from sources with their own terms (a copyrighted chronology, CCEL's Easton XML, Digital Manna). |
| eliranwong/OpenGNT | Mixes components with a separate Bible Hub copyright notice. |
| openscriptures/GreekResources | Upstream notes the restrictive CCAT license. |
| BibleNLP/ebible | A compilation where at least 699 files are CC BY-NC-ND. eBible.org is fetched directly instead, with each translation's license checked. |
| scrollmapper/bible_databases | MIT applies to the code; the bundled translations have mixed and unverified licenses. |
| seven1m/open-bibles | Some "public domain" labels conflict with eBible.org (for example the Korean Revised Version 1952/1961). The same public-domain texts come from eBible.org instead. |
| eBible.org "copyrighted" section (282 translations) and `ropk` (no license page) | Not openly licensed. |
| Sefaria versions with license "unknown", and all `merged.json` files | No confirmed license; merged files mix licensed and copyrighted versions (e.g. JPS 2023 in Genesis). |
| Rahlfs-Hanhart Septuagint, CATSS LXX morphology, eliranwong/LXX-Rahlfs-1935 | Deutsche Bibelgesellschaft copyright; CATSS requires a signed user agreement. |
| NA28, UBS5, BHS, BHQ, Stuttgart Vulgate | Deutsche Bibelgesellschaft copyright. |
| NIV, ESV, NASB, NKJV, NLT, CSB, NRSV, NET, The Message, Amplified and other modern publisher translations | Publisher copyright. |
| BDAG, HALOT, TDNT/Kittel, Louw-Nida, NIDNTT, TWOT text | Publisher copyright (TWOT reference numbers in the Strong's data are index numbers only). |
| Modern commentaries and study Bibles; modern translations of ancient works (e.g. Battles' Institutes, Yale Edwards) | Copyright in the edition or translation. |
| Codex Sinaiticus, Vaticanus, Aleppo Codex, Leon Levy Dead Sea Scrolls, CSNTM manuscript images | Institutional terms; view-only. Link to them, do not copy. |
| Abbott-Smith source PDF (archive.org scan) | The PDF carries its own use restrictions. Only the public-domain TEI text is collected. |
| OpenBible.info place thumbnail images | Mixed image licenses. |
| Bible Gateway, Bible Hub, Blue Letter Bible, StudyLight, New Advent site content | Terms of use do not permit bulk redistribution, even where the underlying text is public domain. |

# Non-commercial material

Nothing is stored in this folder in git. Non-commercial sources are fetched by
`tools/fetch.py` and published only in the separate `noncommercial-archive-YYYY-MM`
release, so they can never be mixed into the open library by accident.

| Source id | What it is | License |
| --- | --- | --- |
| `etcbc-bhsa` | ETCBC Hebrew Bible linguistic database | CC BY-NC 4.0 |
| `etcbc-dss` | ETCBC Dead Sea Scrolls database | CC BY-NC 4.0 |
| `etcbc-peshitta` | ETCBC Syriac Peshitta Old Testament | CC BY-NC 4.0 |
| `ebible-nc` | 748 eBible.org translations | CC BY-NC-ND 3.0 / 4.0 |
| `sefaria-nc` | Sefaria texts licensed CC BY-NC | CC BY-NC |

**Do not use any of this in a paid product**, including a paid study archive or members-only course material. CC BY-NC-ND translations must also stay unmodified.
